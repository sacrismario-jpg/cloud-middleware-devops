# Cloud & Middleware Lab

## Objetivo

Construir un laboratorio práctico de infraestructura IT para
aprender administración de sistemas, middleware, automatización,
monitorización y fundamentos de DevOps.

## Alcance inicial

La primera versión se ejecutará localmente en Zorin OS, sin
dependencias obligatorias de servicios cloud de pago.

El proyecto evolucionará progresivamente para incorporar:

- Una aplicación web sencilla.
- Un servidor web y proxy inverso.
- Automatización mediante Bash y Python.
- Control de versiones con Git.
- Monitorización y análisis de logs.
- Pruebas automatizadas y fundamentos de CI/CD.
- Una posible extensión a AWS o Google Cloud Platform.

## Entorno de desarrollo

- Sistema operativo: Zorin OS 18.1.
- Arquitectura: x86_64.
- Memoria RAM: 8 GB.
- Python: 3.12.3.
- Bash: 5.2.21.

## Seguridad y costes

El desarrollo inicial se realizará en local.
No se crearán recursos cloud facturables sin revisar previamente
los costes y confirmar expresamente su utilización.

No se deben almacenar contraseñas, tokens ni claves privadas
en el repositorio.

## Documentación

La arquitectura, las decisiones técnicas, las pruebas y los
procedimientos de resolución de incidencias se documentarán
progresivamente en el directorio `docs/`.
